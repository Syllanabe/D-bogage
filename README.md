# Débogage et refactoring d'une carte de prix

## Objectif du projet

Ce projet consiste à corriger un composant web défectueux : une carte de prix avec des problèmes de mise en page et un bouton non fonctionnel.

Le composant a été corrigé, amélioré et transformé en composant réutilisable avec HTML, CSS et JavaScript.

## Prompt IA utilisée dans Cursor

```text
Corrige ce composant HTML/CSS de carte de prix.
Identifie les erreurs de mise en page, corrige les fautes de syntaxe HTML/CSS, rends le bouton fonctionnel avec JavaScript, puis transforme la carte en composant réutilisable à partir d'une fonction Card(title, price, features).
Le résultat doit utiliser uniquement HTML, CSS et JavaScript, sans framework.
